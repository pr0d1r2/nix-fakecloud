# Code of Conduct

Be decent. Concretely:

- Assume the other person is trying to help.
- Criticise the code, the packaging, the reasoning — not the person.
- No harassment, personal attacks, or unwelcome attention. This includes
  private messages arising from activity here.
- Disagreement is fine and useful. Contempt is not.
- When someone tells you to stop, stop.

This applies to issues, pull requests, commits, and any other space this
project uses.

If someone breaks it, open an issue or contact the repository owner through
their GitHub profile. Reports will be handled privately. The maintainer may
edit, delete or reject contributions, and may block accounts, without owing an
argument about it.

This is deliberately short. It is not a legal document; it is a statement that
bad behaviour is a maintenance problem like any other, and gets dealt with.
